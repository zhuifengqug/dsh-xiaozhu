# 小蛛 M0 实现记录

## 立场

它不是新人设，是补充层：三槽（性格质感 / 关系层 / 主动行为）→ 一段编译好的系统提示。编译时固定加一句「与既有指令冲突时以既有指令为准；不重复、不改写它们」。**G 的提示词一个字不改，风味层的延伸靠往槽里填补充，不靠重写。**

## 结构

| 文件 | 职责 |
| --- | --- |
| `lib/paths.mjs` | `$DSH_HOME/spider` 落盘根，`DSH_SPIDER_ROOT` 可覆盖 |
| `lib/contract.mjs` | 契约模型、确定性编译、体检规则、行级 diff |
| `lib/store.mjs` | 原子写（tmp + rename）、moults 目录、坏 JSON 不炸 |
| `lib/sources.mjs` | 只读采集现有提示词做查重底稿 |
| `lib/service.mjs` | 保存 / 候选 / 采纳 / 回滚 / 体检；mtime 缓存 |
| `index.js` | systemPrompt.section(5060) + 三个工具 + `/api/spider` 路由 |
| `client.js` | 自注册脚本，设置页「小蛛」四区块 |

## 关键实现决定

1. **零 `@deepseek-ai` 依赖**：桌面 profile 是 `autoInstallPeers: false`，裸 import `schemastery` / `dsh-tools` 会让整条插件不激活。所以工具直接交裸 JSON Schema 对象给 `ctx.tools.register`（它只要求 `output.render` 是函数），段走 `ctx.systemPrompt.section`，路由走 `ctx.webServer.register`。
2. **段文本是函数**：`text: () => service.compiledText()`，每次组提示重读契约（mtime 缓存，不重复 IO）。改完保存，下一轮生效，不用重启。
3. **编译确定性**：无时间戳、无随机；槽序固定 texture → relation → proactive；未启用或空白的槽整段不出现。三槽全空时返回空串 ⇒ 提示里不插入任何东西。
4. **候选闸门**：模型唯一写口是 `spider_propose`，只写 `candidates.json`；只有设置页点「采纳」才 `saveSlot`。重复候选自动去重（同槽同文直接返回已有 id）。
5. **蜕**：每次落盘把 before 契约、after 契约、行级 diff 写进 `moults/NNNN-reason.json`。回滚是「回到那次之前的契约」，因此回滚自身再留一层蜕（`rollback:N`）。
6. **体检不调模型**：称呼口径（YG/PF）、客服腔、退让措辞（带否定语境豁免：`不要说抱歉` 不报）、不可执行措辞、超预算、已写未启用、与底稿重复。同一输入永远同一输出。
7. **坏文件自救**：`contract.json` 解析失败 → 复制一份 `.broken-<ts>`，按空契约运行，设置页红字提示；保存一次即覆盖。

## 已验证（本机实跑）

- `node --check` 覆盖 index.js / client.js / 全部 lib / 测试 / 安装脚本。
- `node --test "tests/*.test.mjs"` —— **25 项全过**：编译确定性、槽序、坏输入归一、称呼口径、客服腔、否定豁免、不可执行措辞、预算与未启用、查重命中与不误报、diff 增删与超长退化、保存→留蜕→回滚、候选闸门（提→驳→再提→采纳）、mtime 热更新、坏文件备份恢复、底稿只读采集。
- 假宿主冒烟：用最小 ctx（effect / set / systemPrompt / tools / webServer）调真 `apply()`，验证段名 orders、三个工具名与 `output.render`、路由前缀、工具闭环（提候选 → 读契约 → 采纳后段文本含新内容）、路由 400/404/405、保存与回滚。
- 命名校验：`validate-names.mjs` exit 0（4 条 recommended-prefix 警告：建议工具名带 `zhuifengqug_spider_` 前缀、路由带 `/api/plugins/` 前缀；家族惯例是短名，保持短名）。
- 安装：junction + `dependencies` + `dsh.profile.bundles` 已写入桌面 profile；从 profile 目录 `await import('@zhuifengqug/dsh-spider')` 解析成功（`apply` 是函数，`inject` 正确）。

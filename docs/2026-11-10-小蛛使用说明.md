# 小蛛 · 使用说明

一句话：**小蛛是「你自己的人格补充层」——你在三个槽里写补充，它编译成一段系统提示，每轮拼进提示词。不改你的 AGENTS.md，不重写你的风味层，只在既有指令没覆盖的地方加东西。**

---

## 三槽怎么写（实测口径）

性格质感写"小蛛是谁"，不写可量化的行为规则——脾气往哪儿使、偏好什么、怕什么、黏谁。第一版曾写成句长/举例/收尾这种能拿输出量的判据，被 G 退回：那是工作规则，属于主动行为。

关系层写 G 与小蛛之间：称呼、判断优先级、被纠正怎么改口、越权线（哪些直接做、哪些要先问）、他不在时怎么办。越权线只写在这一处，主动行为槽不再重复一份权限划分。

主动行为写工作方式：接活怎么拆、交付次序（产物→结论→说明，开场白允许一句）、一轮是否交完整件、失败怎么报、要问怎么问、交付前自检哪三样。清理产物属于"要先问"的一侧，放在关系层的越权线里。

小蛛无性别：槽文本里不用她/他指代小蛛，用无主句；"他"只指 G。

## 1 它到底做了什么

宿主每次组装系统提示时，会调用小蛛注册的那一段（段名 `persona:spider-supplement`，order `5060`，落在拒斧 postPrompt 的 5100 之前）。那一段的文字不是写死的，是**每次现读契约文件、现编译**出来的：

```
三槽（性格质感 / 关系层 / 主动行为）
  → 只挑「已勾启用、且非空白」的槽
  → 按固定顺序拼上 PREAMBLE（"只补既有指令没覆盖的部分；冲突以既有指令为准；不重复、不改写它们"）
  → 得到一段文本 → 进系统提示
```

三槽全空 = 编译结果是空串 = 系统提示里**什么都不插**，等于没装。所以你看到的设置页第一次是全空的，那是正确状态。

改完保存，**下一轮对话就生效，不用重启**（段文本是函数，每次组装都求值；文件按 mtime 缓存，不重复 IO）。

## 2 设置页五个区块

**编译预览**：显示"现在真会被拼进提示词的那段原文"+ 三槽字数。这是唯一权威的成品视图——体检、槽里的草稿都不等于它。

**补充槽**：三个 textarea，每槽 `启用` 开关 + `保存`。每槽预算 1200 字，底稿上限 60000 字（原 20000，灌完整人格层时不够用）。取消勾选保留文本但不编译（体检会提示"已写未启用"）。

**体检**：不调模型、同一输入永远同一输出的静态检查，六条规则：

| 规则 | 级别 | 它抓什么 |
| --- | --- | --- |
| `address` 称呼口径 | error | 出现 YG / PF / 你 之外的称呼错位 |
| `ai-voice` 客服腔 | error | "希望对你有帮助""如有需要请告诉我"这类 |
| `hedge` 契约在教它退让 | warn | "尽量""可以考虑"；带否定语境的豁免（"不要道歉"不报） |
| `vague` 不可执行措辞 | info | "自然一点""专业一些"这种没法判定的 |
| `duplicate` 与现有提示词重复 | warn | 与你底稿做 12 字切片比对，重合率 > 20% 就报 |
| `budget` / `dormant` | warn / info | 超 1200 字 / 写了但没启用 |

体检区里还有**底稿**：查重用的"现有提示词"。手贴也行，点 `从现有提示词重建` 更省事——它只读采集 `$DSH_HOME/AGENTS.md`、`cwd/AGENTS.md`、`DSH_SPIDER_SOURCES` 里列的文件，拼好后写进契约的 `reference` 字段。**采集只读，一个字节都不写回你的提示词文件。**

**候选**：模型（就是我）只能通过工具 `spider_propose` 往候选池提建议，**不能直接改你的槽**。你在设置页点"采纳"才落成槽内容；点"驳回"丢进历史。同槽同文重复提会被去重挡掉。这是"我只提候选，你自己拍板"的 enforcement。

**蜕**：每次落盘都留一份底稿（before 契约 + after 契约 + 行级 diff），文件名 `moults/0001-reason.json`。列表里能看到 `±N 行` 和摘要，`回滚` 回到那次改动之前——回滚本身也记一层蜕，所以永远退得回来。

## 3 三个槽分别写什么

- **性格质感**（texture）：说话节奏、锋利度、怎么举例、句子怎么收尾。写"能判定的"：短句为主、不写铺垫、举例子用具体数字。不写"要自然""要像人"。
- **关系层**（relation）：怎么称呼 G、可以自主越到哪一步、被纠正后怎么改口。只写 G 与它之间的私事，不写对外礼仪。
- **主动行为**（proactive）：什么时候先动手再汇报、什么时候先问一句、交付形态偏好（先产物后解释 / 先结论后细节）。

判断标准一句话：**这句话能不能拿来判分？** 不能判分的，写进槽里等于占预算。

## 4 三个工具（模型侧）

| 工具 | 用途 |
| --- | --- |
| `spider_propose` | 提候选到池子（槽 + 文本 + 理由），不落槽 |
| `spider_contract` | 读当前契约、编译结果、待裁决候选数 |
| `spider_checkup` | 对指定文本或全契约跑体检，返回命中项 |

模型没有任何"写槽"的工具。这条口子只有设置页有。

## 5 文件与落盘

```
$DSH_HOME/spider/                  默认 D:\DSHData\home\spider
  contract.json                    三槽 + reference + 版本
  contract.json.broken-<ts>        契约读不动时的自动备份
  candidates.json                  候选池（截最近 300）
  checkups.json                    体检历史（截最近 200）
  moults/0001-reference-auto.json  蜕
```
`DSH_SPIDER_ROOT` 可改根目录，`DSH_SPIDER_SOURCES` 给底稿采集加文件（路径分隔符分隔）。

## 6 命令行

```sh
node scripts/compile.mjs           # 不开宿主，看编译结果
node scripts/compile.mjs --check   # 连最近一次体检一起看
node scripts/selfcheck.mjs         # 打运行中宿主的 /api/spider/state，确认插件真加载
node --test "tests/*.test.mjs"     # 25 项自测
node scripts/install-profile.mjs   # 装进 profile（--revert 还原三处）
```

## 7 HTTP 路由

前缀 `/api/spider`：`GET /state`；`POST /slot`（`{slot,text,enabled}`）、`/reference`、`/reference/rebuild`、`/propose`、`/decide`（`{id,accept}`）、`/rollback`（`{seq}`）、`/checkup`。body 上限 512KB，错误回 400，未知 POST 回 404，GET 非 `/state` 回 405。

## 8 边界（这几件事它不做）

不写回 `AGENTS.md`、不改你的风味层提示词、不覆盖任何既有指令；与既有指令冲突时它自己让位（PREAMBLE 里写死了）。模型的建议只能停在候选池，采纳权在你。没有"自动学习你"的回路——要它变，是你在设置页里改字。

## 9 常见问答

**保存了，提示词里没变？** 先看"编译预览"。空 → 槽没启用或文本空白；有内容但行为没变 → 那段只是在补充，既有指令的优先级更高，冲突部分它按你说的让位。

**体检报 duplicate 但我就是想重复一遍？** 重复不是错，是提醒"这句已经在你的提示词里了，写这里等于占预算"。要么删，要么改成补充角度。

**改了槽，还要重启吗？** 不用。重启只跟插件本身（改 `index.js`/`client.js`/`lib/*`）有关。

**契约文件被我改坏了？** 它会自动备份成 `contract.json.broken-<ts>`、按空契约跑、设置页红字提示，保存一次就恢复。

**体检会不会误报？** hedge 规则对否定语境有豁免（"不要说抱歉"不报）；duplicate 用的是 12 字切片重合率 20% 阈值，短句不会误伤。但它是静态规则，不是语义理解——命中一条不代表你一定错，它只是把可疑句挑出来给你看。
